# 등산 게임(강사님 구출하기) 기획서

> 이 게임은 🏔️**산 꼭대기에서 추위에 떨고 있는 강사님**🥶을 구조하기 위해 험난한 여정을 떠나는 턴제 게임이다.
> 우선 구조에 나설 🧗‍♀️**등산객을 선택**한 뒤, 매 턴 📜**흥미로운 질문지를 읽고 4개의 선택지** 중 하나를 골라
> 등산객에게 주어진 턴과 체력, 회피 기회를 고려해 **강사님을 구출해야한다!!!**💥


| 항목 | 내용 |
| --- | --- |
| 형태 | Java 콘솔 텍스트 턴제 게임 |
| 화면 | 캐릭터 선택 → 4지선다 선택 → 승리/실패 → 재도전 여부 |
| 승리 조건 | 진행도 100%이고 체력이 1 이상. 최대 턴을 다 쓴 그 턴에 도착해도 승리 |
| 실패 조건 | 체력 0, 또는 최대 턴을 다 썼는데 진행도 100% 미달 |

---

## 1. 이 게임의 핵심

**매 턴마다 질문지를 읽고, 정상으로 향할 수 있는 길을 현명하게 고르는 것**이 핵심 플레이다.

등산객을 고르는 첫 화면.

``` text
등산객을 고르시오
1. 마동석   // 캐릭터 설명
2. 노홍철   // 캐릭터 설명
3. xxx
4. yyy
```

이후 매 턴 화면은 이렇게 나온다. 아래 수치는 민첩한 등산객 기준 예시이다.

```text
[3턴/8턴] 체력 2/2  |  진행도 40% (4/10칸)  |  회피 기회 2  |  민첩한 등산객
귀여운 치이카와를 무시하고 등산에 성공했습니다.     // 이전 턴에서 선택한 선택지 해설
이번엔 등산길 초입에서 카리나가 풀숲에서 유혹합니다.. 어디로 가야할까?  // 다시 질문
강사님은 아직 위쪽에 있다.  // 넣어도 되고 안 넣어도 됨

  1. 따라간다.
  2. 무시한다.
  3. 춤을춘다.
  4. 회피한다. (회피 기회 -1)

선택 >
```

성공 화면
``` text
축하드립니다.🎉 강사님은 이제 무사하십니다.🎊
다시 하시겠습니까? (Y/N)
```

실패 화면
``` text
ㅠㅠ😢 강사님은 여전히 추위에 떨고 계십니다.🥶
다시 하시겠습니까? (Y/N)
```

- 선택지는 항상 **4개**다. 질문은 1개다.
- 번호 순서와 질문은 매 턴 **랜덤이다**. 1번이 늘 안전한 길이 아니다. 4번 선택지만 회피 고정이다.
- 네 선택지 중 **회피만** 문장에 `회피`라고 표시한다. 나머지 셋은 문장만 보여주고, 안전한 길인지 함정인지는 숨긴다.
- 선택지를 고른 뒤 고른 선택에 따라 **체력·진행도·회피**가 다음 턴 화면에 바로 적용된다.
- 올바르게 보이는 길에도 함정이 있을 수 있고, 물론 반대의 경우도 존재한다.
- 산은 **10칸 = 진행도 100%**다. 화면에는 `40% (4/10칸)`처럼 퍼센트와 칸을 같이 보여 준다. 1칸은 10%다.

## 2. 플레이 흐름

결과를 적용한 뒤 **체력 0이거나, 턴을 오버하면 바로 실패**다.
체력이 1이상 남아 있고 진행도가 100%이면 승리이다.

```text
등산객 선택
    ↓
┌─▶ 질문 1개, 선택지 4개 (순서 무작위, 4번 선택지 회피만 표시)
│     ↓
│   결과 적용, 턴 +1
│     ↓
│   체력 0 ?  ──예──▶  구출 실패
│     │
│   아니오
│     ↓
│   진행도 100% ?  ──예──▶  강사님 구출 (승리)
│     │
│   아니오
│     ↓
│   최대 턴을 다 썼나 ?  ──예──▶  구출 실패 (시간 초과)
│     │
│   아니오
└─────┘

승리 또는 실패
    ↓
다시 하시겠습니까? (Y/N)
    ├─ Y → 등산객 선택으로
    └─ N → 종료
```

| 결과 | 조건 |
| --- | --- |
| 구출 성공 | 선택 결과 적용 후 체력 1 이상, 진행도 100% 이상, 사용한 턴이 최대 턴 이하 |
| 쓰러짐 (실패)| 체력 0 실패 |
| 시간 초과 (실패) | 최대 턴을 다 썼는데 진행도가 100% 미만 |

진행도는 100%(10칸)을 넘기지 않고, 0칸 아래로 내려가지 않는다.
체력은 0 아래로 내려가지 않는다. 캐릭터의 최대 체력은 7을 넘기지 않는다. 회복 선택지는 없다.

입력 규칙:

- 캐릭터 선택과 길 선택은 1~4만 받는다. 그 외 입력은 턴을 쓰지 않고 같은 화면을 다시 보여 준다.
- 회피 기회가 0인데 회피를 고르면, 기회가 없다고 알리고 턴을 쓰지 않은 채 같은 질문을 다시 고르게 한다.
- 재도전은 Y 또는 N만 받는다. 그 외 입력은 다시 묻는다. Y는 캐릭터 선택으로 돌아가고, N은 종료한다.

## 3. 캐릭터

수치는 1차 밸런스용이다. 플레이 후 조정.


| 캐릭터 | 체력 | 진행 속도 | 회피 횟수 | 최대 턴 | 특징 |
| --- | ---: | ---: | ---: | ---: | --- |
| 체력맨 등산객 | 5 | 1 | 1 | 10 | 한 턴에 한 칸만 움직이고, 회피도 한 번 밖에 못하지만, 체력이 무려 5칸이다. |
| 민첩한 등산객 | 2 | 2 | 2 | 10 | 애매한 체력과 회피 횟수를 가지고 있지만, 한 질문에 2칸씩 누구보다 빠르게 게임을 진행하는 성격이 급한 등산객. |
| 행운의 등산객 | 1 | 1 | 6 | 10 | 회피 몰빵형 등산객. 회피 6번을 모두 쓰고도 안전한 길 10번을 밟을 턴이 남는다. |
| 의문의 등산객 | 1~7 | 1~3 | 0~6 | 8~16 | 모든 스탯이 랜덤인 의문의 등산객. 고른 직후에 체력, 진행 속도, 회피, 최대 턴이 공개된다. |

## 4. 선택 결과

플레이어에게 보이는 결과는 세 가지다.

| 종류 | 화면 | 결과 |
| --- | --- | --- |
| 안전한 길 | 결과 종류를 숨긴 문장 | 진행 +진행 속도칸. 속도 1은 +1칸, 속도 2는 +2칸, 속도 3은 +3칸. 체력과 회피는 변하지 않는다 |
| 함정 | 결과 종류를 숨긴 문장 | 진행 -1칸, 체력 -1. 속도와 상관없이 같다. 회피는 변하지 않는다 |
| 회피 | 문장에 `회피`를 표시 | 회피 기회 -1. 진행과 체력은 변하지 않는다 |

- 질문마다 선택지 4개 = 안전한 길 1게 + 함정 2개 + 회피 1개.
- 4번의 선택지 회피만 고정이고, 나머지 1번, 2번, 3번의 안전한 길과 함정은 랜덤으로 결정된다.
- 회피를 골라도 턴은 1 지나가고, 그 자리에 머문다.
- 선택한 결과의 한 줄은 다음 턴 화면 맨 위에 나온다. 첫번째 선택 화면에서는 선택을 하지 않았으므로 등장하지 않는다.

## 5. 질문지와 선택지 예시

한 판에서 이미 나온 질문은 다시 내지 않는다. 목록을 다 쓰면 다시 섞되, 바로 직전 질문과는 겹치지 않게 한다.
아래 번호는 데이터 기준이다. 게임 안에서는 네 선택지의 순서를 매번 섞는다.
`안전`과 `함정` 표기는 기획서에만 있고, 플레이어 화면에는 나오지 않는다. 회피만 표시된다.

질문1. 귀여운 치이카와가 등산로 한가운데 앉아 도시락을 내민다.
1. 도시락을 받고 같이 앉는다. — 함정
2. 옆으로 돌아가 올라간다. — 안전
3. 치이카와보다 먼저 먹기 경쟁을 한다. — 함정
4. 회피한다. (회피 기회 -1) — 회피

질문2. 등산길 초입에서 카리나가 풀숲에서 유혹한다.
1. 따라간다. — 함정
2. 무시한다. — 안전
3. 춤을 춘다. — 함정
4. 회피한다. (회피 기회 -1) — 회피

질문3. 펭수가 이정표 화살표를 반대로 돌려 놓고 엄지를 치켜든다.
1. 화살표가 가리키는 쪽으로 간다. — 함정
2. 화살표를 되돌리고 원래 방향으로 간다. — 안전
3. 펭수에게 사진을 부탁하고 지나간다. — 안전
4. 회피한다. (회피 기회 -1) — 회피

질문4. 잔망루피가 배낭 지퍼를 열고 간식을 꺼내 먹고 있다.
1. 간식을 뺏어 힘을 낸다. — 함정
2. 배낭을 닫아 주고 올라간다. — 안전
3. 같이 앉아 간식을 나눈다. — 함정
4. 회피한다. (회피 기회 -1) — 회피

질문5. 좁은 바위틈을 거대한 주먹밥이 가로막고 있다.
1. 주먹밥을 한 입 베어 물고 지나간다. — 함정
2. 바위를 타고 우회한다. — 안전
3. 주먹밥이 굴러가도록 밀어 본다. — 함정
4. 회피한다. (회피 기회 -1) — 회피

질문6. 산신령이라며 두건을 쓴 사람이 등산화 한 짝을 제물로 요구한다.
1. 등산화를 벗어 준다. — 함정
2. 신발은 거절하고 정해진 등산로로 간다. — 안전
3. 제물 대신 간식 하나만 건네고 지나간다. — 안전
4. 회피한다. (회피 기회 -1) — 회피

질문7. 안개 속에서 서로 다른 방향을 가리키며 "정상이 저쪽!" 하는 목소리가 들린다.
1. 더 큰 목소리를 따라간다. — 함정
2. 나침반과 지도에 적힌 능선으로 간다. — 안전
3. 두 목소리의 중간으로 직진한다. — 함정
4. 회피한다. (회피 기회 -1) — 회피

질문8. 카리나 응원봉을 든 무리가 정상 대신 포토존으로 손을 잡아끈다.
1. 포토존으로 따라간다. — 함정
2. 손을 놓고 능선을 따라 올라간다. — 안전
3. 응원봉을 빌려 들고 같이 구호를 외친다. — 함정
4. 회피한다. (회피 기회 -1) — 회피

## 6. 완성 체크

- [ ] 시작 시 캐릭터 4종 중 하나를 고른다.
- [ ] 매 턴 선택지가 4개이고, 순서가 섞인다. 회피 선택지만 문장에 직접적으로 회피가 나온다.
- [ ] 안전한 길은 진행 속도만큼 칸이 오르고, 함정은 진행 -1칸·체력 -1, 회피는 회피 기회만 -1이다.
- [ ] 등산객은 모두 턴이 10번 주어진다. 의문의 등산객은 선택 직후 랜덤으로 정해진 최대 턴을 따른다.
- [ ] 진행도 100%이고 체력이 1 이상이면 강사님 구출이다. 체력 0이면 실패다. 최대 턴을 다 썼는데 100%가 아니면 실패다.
- [ ] 숫자 아님·범위 밖 입력은 다시 받는다. 회피가 0인데 회피를 고르면 턴을 쓰지 않고 다시 받는다.
- [ ] 질문 문장을 추가해도 턴 진행 코드는 그대로다.
- [ ] 승패 후 Y를 고르면 캐릭터 선택으로 돌아간다.
